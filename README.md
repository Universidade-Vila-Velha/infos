# Repositório de Identidade Visual UVV

Este repositório contém os elementos essenciais da identidade visual da **UVV**, incluindo as versões oficiais do logotipo, paletas de cores, e gradientes utilizados para garantir a consistência da marca.

## Conteúdo do Repositório

O repositório contém os seguintes arquivos:

1. **Logotipos UVV**  
   - Formatos: PDF, PNG, JPG

2. **Logotipos UVV 2019**  
   - Formatos: PDF, PNG, JPG

3. **Paleta de Cores Padrão**  
   - Cores utilizadas na identidade visual da UVV

4. **Gradientes Oficiais**  
   - Gradientes aprovados para uso nos materiais gráficos

## Como Utilizar

Abaixo estão as recomendações para garantir que a identidade visual da UVV seja aplicada de forma consistente:

### Logotipos
- Utilize os logotipos conforme as orientações especificadas no repositório.
- Os logotipos estão disponíveis em três formatos: **PDF**, **PNG** e **JPG**.
- Prefira sempre utilizar a versão mais alta resolução disponível para garantir a melhor qualidade.

### Orientações de Uso dos Logotipos
- **Logotipo Vertical:** Utilizar quando o espaço for estreito e vertical.
- **Logotipo Horizontal:** Ideal para situações em que o espaço disponível é mais largo.
- Não modifique ou distorça os logotipos de nenhuma forma.

### Paleta de Cores
- Utilize as cores da paleta padrão em todos os materiais visuais.
- As cores foram selecionadas para manter a integridade visual da marca.

### Gradientes
- Utilize apenas os gradientes oficiais fornecidos.
- Os gradientes devem ser aplicados conforme indicado, respeitando as transições e combinações de cores.
